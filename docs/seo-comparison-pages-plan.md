# Plundrix SEO Comparison Pages Plan

Generated: 2026-05-18

This plan captures the first comparison-page strategy for Plundrix. The goal is not to claim every popular game is a direct competitor. The goal is to meet searchers at adjacent intent: casual raid games, digital board games, sabotage/social games, and onchain strategy games.

## Positioning Principles

1. Be fair to the compared game.
2. Compare player intent, not just surface genre.
3. Avoid unsupported superiority claims.
4. Use Plundrix's actual differentiators: short turn-based vault races, pick/search/sabotage decisions, visible table pressure, onchain sessions, replay proof, explicit bot/agent labeling, simulator-backed tuning, and launch/readiness tooling.
5. Make each page useful even if the visitor already likes the compared game.
6. Keep pages evergreen by focusing on mechanics and player fit, not temporary promotions.
7. Link to official sources where a comparison depends on another game's published positioning.
8. Make the pages internally connected so searchers can move from one adjacent intent to another.

## First-Wave Pages

1. `/compare/coin-master-alternative`
   - Search intent: raid, attack, loot, casual progression, social mobile game alternative.
   - Plundrix angle: if you like raid/attack loops but want more turn-by-turn agency, Plundrix is a vault race with decisions each round.
   - Evidence hook: Coin Master officially describes attacks and raids.

2. `/compare/monopoly-go-alternative`
   - Search intent: Monopoly GO alternative, heist/bank event alternative, quick social game.
   - Plundrix angle: if you like quick table drama and heist energy but want fewer passive loops, Plundrix is a direct-action vault contest.
   - Evidence hook: Monopoly GO officially describes Bank Heist-style events.

3. `/compare/catan-online-alternative`
   - Search intent: online board game, Catan alternative, resource strategy alternative.
   - Plundrix angle: if you like resource pressure and multiplayer reads but want shorter, meaner sessions, Plundrix trades settlement building for vault pressure.
   - Evidence hook: CATAN is officially positioned around trading, building, and settlement.

4. `/compare/risk-online-alternative`
   - Search intent: Risk alternative, online strategy board game, shorter turn-based strategy.
   - Plundrix angle: if you like turn-based competitive pressure but not long map conquest, Plundrix compresses the table fight into a vault race.
   - Evidence hook: Risk: Global Domination is an official digital Risk experience.

5. `/compare/among-us-board-game-alternative`
   - Search intent: social sabotage game, Among Us alternative, no voice chat sabotage game.
   - Plundrix angle: sabotage and suspicion without hidden-role voice-chat dependence.
   - Evidence hook: Among Us is broadly recognized for social deduction and sabotage.

6. `/compare/munchkin-alternative`
   - Search intent: backstabbing card/board game alternative, funny unfair multiplayer game.
   - Plundrix angle: backstab-your-friends energy in a faster digital vault race with visible progress and replayable outcomes.
   - Evidence hook: Munchkin is officially positioned around backstabbing friends and stealing stuff.

7. `/compare/onchain-board-game`
   - Search intent: onchain board game, blockchain board game, web3 strategy game.
   - Plundrix angle: a short-session board-game-like onchain vault contest, not a sprawling economy or abstract protocol demo.
   - Evidence hook: use Plundrix's own product facts and link to developer docs.

8. `/compare/pirate-nation-alternative`
   - Search intent: fully onchain game alternative, Pirate Nation alternative, onchain casual game.
   - Plundrix angle: session-based competitive vault races instead of broader RPG/progression loops.
   - Evidence hook: Pirate Nation docs describe its onchain technology posture.
