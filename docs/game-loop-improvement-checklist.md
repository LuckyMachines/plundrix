# Game Loop Improvement Checklist

Date: 2026-09-07
Baseline loop grade: B-

## P0 - Core and live blockers

- [x] Add visible final-lock counterplay and validate both fresh-table fairness and comeback pressure.
- [x] Reduce dead sabotage outcomes without restoring chain-stun frustration. Protected targets are excluded by agents; empty-target stuns remain intentional leader interruption rather than false failures.
- [x] Add parity tests for the local engine and Solidity resolution rules.
- [x] Surface the deployed Workshop, paced games, and session-action readiness through one runtime capability check.
- [x] Add invitation and waiting-room continuity to live operations.

## P1 - Consequence and continuation

- [x] Save every completed local operation as its exact replay rather than sending the player to a simulated gallery.
- [x] Add a local career surface for identity, results, ranks, rivals, runs, collection, and next objectives.
- [x] Make salvage partially targetable through the actions and routes used during a match.
- [x] Rebalance fresh local inventory around one intentional first craft while preserving a separate preview sandbox.
- [x] Add visible cosmetic mastery rewards without adding hidden power.

## P2 - Run, rivalry, and recurring play

- [x] Add between-stage contraband choices to Vault Run.
- [x] Give heat explicit thresholds and route-specific encounter consequences.
- [x] Preserve completed and failed run history with personal bests.
- [x] Turn rivalry grudges into announced, bounded encounter modifiers and revenge objectives.
- [x] Expand weekly variety and submit a replayable proof instead of trusting a score alone.
- [ ] Add durable weekly storage when a production database binding is available. Blocked on a production database binding; the current service is process-memory beta storage and says so in the UI.

## P3 - Validation and release

- [x] Run the full simulator, replay, inventory, agent-service, browser, and Solidity suites.
- [x] Re-run the comeback lab against the strict thresholds.
- [x] Re-grade the loop ecosystem and record the new snapshot in the product report card.
- [ ] Validate the journey with first-time and returning human players after deployment. This requires recruited participants and a deployed build.

## Strict A bar

- A fresh four-player table retains a win spread below 5 percentage points.
- The comeback lab keeps the starting leader below 45% wins, gives at least two trailing seats 8% or better, and holds runaway games below 25%.
- A completed local match creates an exact replay, an understandable reward, and one obvious next action.
- A player can name how to pursue a desired craft before leaving the result screen.
- Vault Run changes the player's build or constraints between stages rather than merely repeating three matches.
- Live play reaches the first action in under two minutes and does not require one wallet approval per round after a bounded session authorization.
- Weekly scores are durable and can be independently replayed or verified.
