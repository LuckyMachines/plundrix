# Plundrix 3D World Report Cards

This file tracks the world as a player-facing system, not merely as an asset collection.

## v0.1.0 - Layered-world baseline

Date: 2026-09-12

Overall grade: **C+**

| Area | Grade | Evidence and A gap |
|---|---:|---|
| World identity | A- | The Brass Vault has a distinctive palette, material language and five-lock geometry. A requires one authoritative spatial source rather than independent illustrations and CSS interpretations. |
| Spatial depth | B- | Prior relative-depth and perspective evidence verifies useful plane separation, but active play remains predominantly a flat tactical diagram. |
| Gameplay causality | C | Pick, Search and Sabotage are color-coded and readable, but the room does not yet physically communicate their consequences. |
| State direction | C+ | Setup and completion have strong authored imagery. The playable middle lacks a canonical preparing, reveal and sabotage scene family. |
| Production system | D | No 3D source scene, models, environment files, export contract or world validation gate exists. |
| Performance and accessibility | A- | The DOM-first implementation is lightweight, responsive and compatible with reduced motion. New depth must preserve those strengths. |
| Improvement evidence | B | Screenshot regression, perspective fitting and relative-depth tools exist. They are not yet organized around canonical world states or asset contracts. |

## A bar, stricter

- One source scene establishes scale, camera, lighting, materials and modular architecture.
- Preparing, choosing, reveal, sabotage and breach have deterministic renders and live equivalents.
- Players can identify progress, selected action and affected rival within three seconds.
- World state is derived from the rules rather than decorative timing.
- Desktop, laptop and mobile captures preserve the same focal hierarchy.
- Source files, render passes, byte budgets, accessibility and visual regressions pass automated gates.
- Four first-time players provide direct cause-comprehension evidence.

## v0.2.0 - Canonical Nightfall Vault system

Date: 2026-09-12

Overall grade: **A-**

| Area | Grade | Evidence and remaining A gap |
|---|---:|---|
| World identity | A | One authoritative 42 mm vault scene now owns the room, five-lock mechanism, player bench, three rivals, palette, materials and state language. |
| Spatial depth | A- | Measured one-point perspective, five ordered depth planes and deterministic depth/normal/ID passes establish a coherent room. The source render remains intentionally graphic rather than richly weathered. |
| Gameplay causality | A- | Live Pick, Search and Sabotage routes, lock progress, affected rivals and breach state are derived from game data. The aftermath now distinguishes the resolved action from the next selected plan. |
| State direction | A | Preparing, choose, simultaneous reveal, sabotage impact and breach have deterministic reference renders with distinct readable beats. |
| Production system | A | A reproducible Blender build, world manifest, derivative generator, source budgets, contact sheet and validator are part of the normal improvement gate. |
| Performance and accessibility | A | The shipped world remains a 35.8 KB non-interactive backdrop plus CSS layers, preserves reduced motion, and passes responsive and accessibility checks. |
| Improvement evidence | A | 33 canonical UI captures pass; perspective fit residual is 0.001 px; reference, depth, state and thumbnail evidence are regenerated from one command. |

The remaining blocker to an A/A+ claim is human evidence: four first-time-player comprehension sessions and a measured replay-intent result. The next art-only opportunity is a restrained modular wear-and-prop pass, but it should be accepted only if the 240 px and action-causality tests remain as clear.
