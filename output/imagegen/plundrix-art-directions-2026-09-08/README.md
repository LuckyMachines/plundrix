## Recommendation

Build the production direction from 60% Impossible Blueprint, 25% Punchcard Caper, and 15% Cut-Paper Caper. Reserve Brass Dossier's richer material treatment for vault closeups, rare gadgets, and reward moments.

This mix gives the game a distinctive strategic world while keeping the system realistic for a solo developer to implement and maintain.
