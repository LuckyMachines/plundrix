# Synthesized Design Implementation

The recommended art direction is implemented in the Instant Play operation loop as a functional caper workbench, not a flattened concept-art backdrop.

## Implemented hierarchy

- Live status rail: operator, clearance, tools, round, locks, and heat.
- Left briefing stack: mission status, objectives, threat, and crew readiness.
- Center planning surface: routed blueprint, mechanical vault, lock rail, and honest inventory slots.
- Right operation file: security, race pressure, current plan, potential loot, and a live handler directive.
- Bottom command surface: Pick, Search, Sabotage, tactical preview, Confirm Move, and auto-play.
- Mobile decomposition: vault-first scan, compact status line, and persistent selected-action controls.

## Deliberate differences from the image study

- Text contrast and whitespace are cleaner for real play.
- Decorative props are reduced so interactive state remains obvious.
- Rival identity uses abstract masks plus gadget signals instead of drifting into animal-character art.
- The tool tray reflects carried inventory instead of repeating action artwork.
